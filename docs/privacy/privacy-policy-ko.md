## 2. 요약

이 앱은 **사용자가 선택한 기기의 폴더**와, 선택 사항으로 **사용자가 직접 입력한 Nextcloud 서버**에서 전자책을 읽습니다. 개발자는 이 앱을 위한 서버를 운영하지 않으며 사용자나 사용자의 기기에서 **어떠한 데이터도 받지 않습니다**. 이 앱에는 **광고, 추적, 분석, 충돌 보고 기능이 없습니다**.

## 3. 앱이 처리하는 데이터

앱은 작동을 위해 기기에서 다음 데이터를 처리합니다.

- **로그인 정보:** Nextcloud 서버 주소, 사용자 이름, 앱 암호. 브라우저로 로그인할 때(Nextcloud Login Flow) 서버가 앱 암호를 만듭니다. 앱 암호는 Android Keystore로 암호화하여 저장합니다. 앱은 실제 Nextcloud 암호를 알 수 없습니다.
- **서재 데이터:** 책의 제목, 저자, 시리즈, 장르, 태그, 표지 및 기타 정보, 그리고 책장.
- **책 파일:** 오프라인으로 읽기 위해 다운로드한 파일. 앱 전용 저장 공간에 저장합니다.
- **로컬 폴더:** 폴더를 서재로 추가하면 앱은 그 폴더의 책 파일을 읽습니다(Android 폴더 선택기를 통해 해당 폴더만). 이런 서재의 제목, 표지 및 기타 정보, 읽은 위치, 하이라이트는 기기에만 남습니다. 사용자가 책을 Nextcloud 계정으로 직접 복사하거나 이동할 때만 파일, 읽은 위치, 하이라이트를 해당 서버로 보냅니다.
- **읽기 데이터:** 읽은 위치, 읽기 상태, 평점, 하이라이트, 메모, 그리고 사용자가 정한 기기 이름(기본값: 기기 모델). 기기 이름은 읽은 위치와 함께 전송되므로 다른 기기에서 어디까지 읽었는지 확인할 수 있습니다.
- **앱 설정:** 테마, 리더 설정 등. 이 데이터는 기기에만 남습니다.

## 4. 데이터 전송 위치

데이터는 **사용자의 기기와 사용자가 앱에 입력한 Nextcloud 서버 사이에서만** 전송되며, 항상 HTTPS로 암호화됩니다. 그 서버에서의 처리는 서버 운영자가 책임집니다. 서버를 직접 운영하면 사용자 본인이, 그렇지 않으면 클라우드 제공업체가 운영자입니다. 운영자의 개인정보 처리방침이 적용됩니다.

데이터를 개발자나 다른 제3자와 공유하지 않습니다.

책 안의 링크는 사용자가 확인한 후에만 기기의 브라우저에서 열립니다. 방문한 웹사이트에는 해당 웹사이트의 개인정보 처리방침이 적용됩니다.

## 5. 권한

- **인터넷 및 네트워크 상태:** 서버에 연결합니다. 사용자가 선택하면 Wi-Fi에서만 다운로드합니다.
- **알림:** 다운로드 진행 상황과 완료를 알립니다. Android 설정에서 언제든지 끌 수 있습니다.
- **포그라운드 서비스(데이터 동기화):** 앱이 백그라운드에 있어도 큰 파일을 안정적으로 계속 다운로드합니다.

앱은 위치, 연락처, 카메라, 마이크, 기타 파일에 접근하지 않습니다.

## 6. 보관 및 삭제

모든 데이터는 사용자가 삭제할 때까지 기기에 남습니다.

- 앱에서 "**계정 제거**"를 선택하면 해당 계정의 모든 로컬 데이터(서재, 다운로드한 책, 로그인 정보)를 삭제하고 서버에서 앱 암호를 폐기합니다. 로컬 폴더의 경우 서재, 읽은 위치, 하이라이트를 삭제하고 폴더 접근 권한을 반환합니다. 폴더의 책 파일은 그대로 유지됩니다.
- 앱을 **제거**하면 모든 로컬 데이터가 삭제됩니다.
- 다운로드한 책은 "다운로드"에서 언제든지 삭제할 수 있습니다.

읽은 위치, 하이라이트, 책장 등 Nextcloud 서버에 있는 데이터는 서버에서 직접 관리합니다.

## 7. 법적 근거

기기에서의 처리는 사용자가 요청한 기능을 제공하기 위한 목적으로만 이루어집니다(GDPR 제6조 제1항 (b)). 개발자는 개인 데이터를 처리하지 않습니다.

## 8. 사용자의 권리

GDPR에 따라 사용자는 열람, 정정, 삭제, 처리 제한, 데이터 이동, 처리 반대에 대한 권리와 감독 기관에 민원을 제기할 권리가 있습니다. 개발자는 사용자의 데이터를 받지 않으므로 서버에 저장된 데이터에 대해서는 서버 운영자에게 문의하세요. 앱에 관한 질문은 위의 이메일 주소로 보내 주세요.
