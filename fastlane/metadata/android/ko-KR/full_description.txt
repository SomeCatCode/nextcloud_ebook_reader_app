기기의 폴더나 내 Nextcloud에 있는 전자책과 만화를 어디서나, 오프라인에서도 읽어 보세요.

서버 없이도 사용할 수 있습니다. 휴대폰이나 SD 카드의 폴더를 선택하기만 하면 앱이 제목, 저자, 시리즈, 표지가 있는 서재를 만듭니다. "E-Book Reader" 앱이 설치된 Nextcloud가 있다면 함께 연결하세요. 서재, 책장, 시리즈, 읽은 위치가 모든 기기와 브라우저에서 동기화됩니다.

서버 필요 없음: 로컬 폴더
• 기기의 폴더 하나 이상을 하위 폴더까지 포함하여 각각 별도의 서재로 사용
• EPUB, FB2, CBZ에서 제목, 저자, 시리즈, 설명, 표지를 읽어 옴
• 읽은 위치, 하이라이트, 메모는 기기에 저장
• 저장소 권한 불필요: 앱은 사용자가 선택한 폴더만 볼 수 있음

복사 및 이동
• 책을 다른 계정으로 복사(예: 휴대폰 폴더에서 Nextcloud로, 또는 그 반대로)
• 이동도 가능: 복사한 후 원본 삭제
• 읽은 위치와 하이라이트도 함께 옮겨짐

서재
• EPUB, MOBI, AZW3, FB2와 만화(CBZ, CBR, CB7, CBT) 지원
• 격자 보기와 목록 보기, 검색, 정렬, "이어 읽기"
• 웹과 같은 필터: 트리 형태의 장르와 태그, 저자, 시리즈, 형식, 누락된 메타데이터. 조건 포함 또는 제외
• 다 읽은 책 숨기기, 읽기 상태와 평점
• 책장과 스마트 책장 만들기 및 관리, 권 순서로 정렬된 시리즈

읽기
• 밝은 테마, 세피아, 어두운 테마, 글자 크기, 줄 간격, 여백을 설정할 수 있는 편안한 리더
• 페이지 넘기기 또는 스크롤, 목차, 탭 영역, 볼륨 키로 페이지 넘기기
• 만화 확대(핀치, 두 번 탭), 두 쪽 보기, 만화책을 위한 오른쪽에서 왼쪽 읽기
• 세로 스크롤 만화(웹툰)는 위에서 아래로 끊김 없이 스크롤
• 기기의 음성으로 텍스트의 언어에 맞춰 소리 내어 읽기
• 하이라이트와 메모를 웹 앱과 동기화
• 읽은 위치 자동 동기화. 다른 기기에서 더 많이 읽었다면 앱이 확인
• 고대비, 애니메이션 없는 전자잉크 모드

오프라인
• 책, 책장 전체, 시리즈 전체를 오프라인으로 사용
• 고정한 시리즈와 책장의 새 권은 자동으로 다운로드
• 원하면 Wi-Fi에서만 다운로드

여러 계정
• 여러 Nextcloud 계정과 로컬 폴더를 따로 또는 하나의 통합 서재로 사용
• 계정을 비활성화하면 제거하지 않고 책만 숨김
• 브라우저를 통한 안전한 로그인(Nextcloud Login Flow). 앱은 암호를 알 수 없음

개인정보 보호
광고, 추적, 분석이 없습니다. 로컬 서재는 기기에 남습니다. Nextcloud를 사용할 때도 데이터는 사용자의 기기와 사용자의 서버 사이에서만 전송됩니다.

NEXTCLOUD(선택 사항)
동기화, 책장, 브라우저에서 읽기를 사용하려면 "E-Book Reader" 앱 버전 1.0.0 이상이 설치된 Nextcloud 서버가 필요합니다(Nextcloud App Store 또는 GitHub). 로컬 폴더에는 서버가 필요 없습니다.

비공식 앱이며 Nextcloud GmbH와 관련이 없습니다. Nextcloud는 Nextcloud GmbH의 상표입니다.
